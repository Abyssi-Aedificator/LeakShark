# AGENTS.md

Single-file vanilla web app (no build, no packages, no tests). All markup, CSS, and JS live in `index.html`. The rest are PWA assets.

## Environment

- **No Node/npm.** Don't run `npm`/`node` commands.
- **Python 3.14 + Pillow 12 are available** and are the tools of choice for verification and asset generation.

## Critical gotchas

- **`index.html` must stay UTF-8 without BOM.** Never round-trip it through PowerShell `Set-Content` (default/`-Encoding UTF8` corrupts non-ASCII chars like `·` and the arrow entity into mojibake). Edit via the edit/write tools; they handle encoding correctly.
- **Service worker is cache-first on `index.html`.** After any HTML/CSS/JS change, bump `VERSION` in `sw.js` (e.g. `v1.1.0` → `v1.1.1`), or installed clients keep serving the old file.
- **PWA/offline only works over HTTP(S)/localhost** (`python -m http.server 8080`). Via `file://` the SW registration is skipped by design (`/^https?:$/.test(location.protocol)` in `index.html`).

## Data model

- Subscriptions live in `localStorage` under key **`subman_bento`** (intentionally NOT renamed to avoid orphaning user data).
- A sub is `{ id, name, cost, cycle, renewal, cancel? }`. `cancel` is an optional `YYYY-MM-DD` date.
- **Active/Inactive is derived**, not stored: a sub is Inactive once its `cancel` date passes (`isActive()` in the script). Stats only count active subs.

## Verification

- No test/lint framework. After editing the inline JS, sanity-check balance with:
  `python -c "import re; js=re.findall(r'<script>(.*?)</script>', open('index.html',encoding='utf-8').read(), re.S)[-1]; print(js.count('{'), js.count('}'), js.count('('), js.count(')'))"`
- Keep HTML/class names consistent — no bundler will catch stale IDs/selectors.

## Conventions

- Changelog format: `Version X.Y.Z` followed by `- bullet` lines (see `changelog.txt`). Changelog stays minimal: existing features are already part of their shipped version, so only new post-1.0.0 work gets a bullet.
- Branding is **LeakShark** (title, header, manifest, README). Icon: shark fin + drips.

## Workflow

- After finishing each feature: update `changelog.txt`, commit, then update `AGENTS.md` if needed.
- Each bug fix or feature change must be a separate, individual commit.
- Never include version numbers in commit descriptions.
- Do not push to origin unless explicitly asked.
